# COCOON — MIL-SPEC Thermal Shelter Platform (frontend)

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 3.4

```bash
npm install
npm run dev        # http://localhost:3000 → redirects to /login
npm run build      # production build + type check
```

## Structure

```
src/
├── app/
│   ├── (auth)/            # minimal shell (brand mark, no AppHeader)
│   │   ├── login · register · forgot-password · reset-password
│   ├── (app)/             # AppHeader shell
│   │   ├── dashboard
│   │   ├── projects · benchmark-library · reports       # "In Development" placeholders
│   │   ├── shelter-configurator/step-1 … step-5          # Mode A wizard (PRD v4 §7.1); /shelter-configurator → step-1
│   │   └── candidate-telemetry · candidate-telemetry/[id]
│   └── page.tsx           # → /login
├── components/
│   ├── layout/            # AppHeader, BrandMark, PageHeader, EmptyState, InDevelopmentNotice
│   ├── configurator/      # ConfiguratorStepper, WizardFooter (shared by all steps)
│   └── ui/                # Button, Badge, Card — DESIGN.md primitives
└── lib/
    ├── routes.ts          # single source of truth for every path + nav + wizard phases
    └── mock-data.ts       # fixtures lifted from Stitch (swap for API calls)
```

## Conventions

- Never hard-code a path — import `ROUTES` from `@/lib/routes` (`ROUTES.shelterConfigurator.step2`, `ROUTES.candidateDetail(id)`).
- Nav active state is derived from `usePathname()`; nested routes (e.g. `/candidate-telemetry/C-8042-4`) keep their parent item active.
- Design tokens live in `tailwind.config.ts`. Converted Stitch screens use the Stitch token names
  (`surface-container-*`, `font-label-mono-*`); new UI uses the DESIGN.md semantic palette
  (`navy`, `thermal`, `equilibrium`, `teal`, `plum`, `critical`, `line`, `ink`).
- **Languages (English / हिन्दी):** wrap UI text in `<T>…</T>` (server or client components) or use `useT()` for
  attributes. Hindi strings live in `src/lib/i18n/hi.ts`, keyed by the English text; missing keys fall back to English.
  The toggle (`LanguageToggle`) sits in the app header and the auth screens' top-right corner; the choice is saved per browser.
- **Shelter Configurator** collects only the PRD v4 §7.1 `requirements.schema.json` fields
  (`src/lib/configurator/requirements.ts` holds types, defaults, validation and the JSON builder).
  Geometry, assemblies, windows, gains and infiltration are generated by M2/M4, not entered.
  The draft is shared across steps by `WizardProvider` and autosaved per browser.
- Original Stitch exports are kept for reference in `stitch-exports/`.
